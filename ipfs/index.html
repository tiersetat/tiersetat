Tiers-État

Cette page ne dépend d'aucun serveur de Tiers-État. Hébergée hors de notre infrastructure (IPFS, GitHub Pages), elle lit les mèmes directement sur la blockchain Solana et te laisse les échanger avec ton propre wallet. Elle reste disponible même si le site principal est hors ligne.

Point d'accès à la blockchain (RPC). Si la lecture échoue, colle l'adresse d'un autre fournisseur.

Les memecoins sont spéculatifs : tu peux tout perdre. Réservé aux 18 ans et plus. Aucun conseil financier. Code source : github.com/axel9lg/tiersetat.
