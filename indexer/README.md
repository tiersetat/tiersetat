# Indexeur Tiers-État

Écoute en continu le programme pump.fun sur le réseau principal de Solana (lecture seule) et sert le marché en direct.

- `MAINNET_WSS_URL` : websocket RPC (Helius) du réseau principal
- `ALLOWED_ORIGINS` : sites autorisés à lire l'API (séparés par des virgules)
- `PORT` : port HTTP (8787 par défaut)

Lancement : `npm install && npm start`
